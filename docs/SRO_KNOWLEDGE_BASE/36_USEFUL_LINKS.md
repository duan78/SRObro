### Trackers de statistiques (données officielles iSRO mesurées en direct)

#### M3 Stats — page « Uniques »
- **URL** : https://www.m3stat.com/uniques
- **Description** : tracker des serveurs officiels iSRO (Minerva, Palmyra…) — table **HP/niveau des uniques mesurée en jeu**, y compris les boss 111+ qui manquent à la plupart des bases : Kidemonas (120) 13 851 102 HP, Karkadann (123) 15 023 129, Merikh (125) 18 372 504, Medusa 183 535 199
- **Fiabilité** : ★★★★★ [OFFICIEL-DÉRIVÉ] — ⚠️ la ligne « Roc : 1 451 891 045 HP » est d'ordre de grandeur atypique (possiblement version raid/événement), à recouper avant usage
- **Complément** : le calculateur SP https://www.m3stat.com/SPCalc/ est déjà référencé dans [Outils et Calculators](#outils-et-calculators)

#### ProjectHax Stats
- **URL** : https://stats.projecthax.com
- **Description** : suivi **en direct** de 26 serveurs officiels (7 iSRO, kSRO, jSRO, 7 cSRO-R, DIGEAM, 4 TRSRO, 2 ruSRO, 3 VTC) : population, capacité, guildes, kills d'uniques, chat global — unique outil de veille sur la santé du jeu officiel
- **Fiabilité** : ★★★★★ [OFFICIEL-DÉRIVÉ]

### Annuaires de serveurs privés (compléments des toplists)

#### SRO.GG
- **URL** : https://sro.gg/en
- **Description** : fiches par serveur (cap, degrés, files) avec compteur « online » lu automatiquement sur les sites des serveurs ; pages dédiées par cap (ex. cap 140 : https://sro.gg/en/140-cap-silkroad-servers — définit le contenu high-cap : « au-delà du Jupiter Temple et de l'Arabian Shore, tout est custom »)
- **Fiabilité** : ★★★★ (structure) / ★★ (compteurs auto-déclarés)

#### Nostalgic.gg
- **URL** : https://nostalgic.gg/en/blog/best-silkroad-online-private-servers-en
- **Description** : top ~94 serveurs actifs classés par **population Discord réelle** (méthode anti-fraude de votes, 257 791 membres cumulés) : Golden SRO 2 707 online / 24 988 Discord, Legion SRO 754 / 11 821… — la photographie la plus fiable de la scène ; montre que le high-cap est une niche (aucun 120+ dans le top 10)
- **Fiabilité** : ★★★★

### Communautés arabes

#### Silkroad4Arab
- **URL** : https://www.silkroad4arab.com/vb
- **Description** : LE forum arabe historique (« الموقع العربي الاول للعبة Silkroad Online ») — guides chiffrés dès 2008 (alchimie, SP farming, Fortress War), **~120 sous-forums de serveurs privés en 2015**, sections dev (PK2 Edit f=183, Data Base f=633, ST-Filter f=689) et B/S/T par serveur iSRO. 313 016 membres fin 2015, record **17 621 connectés** le 16/07/2014 (captures Wayback) ; quasi dormant en 2026
- **Fiabilité** : ★★★★★ (existence/stats) / ★★★★ (contenu des guides)

#### ProBasha
- **URL** : https://probasha.com (+ forums : https://probasha.com/forums)
- **Description** : forum dev arabe moderne (XenForo, Égypte) — « le plus grand site arabe des serveurs privés Silkroad (vSRO et iSRO) » : tutos complets de création de serveur vSRO **en arabe** (SQL Server 2014+, port 15779, SR_ShardManager/GameServer, AgentServer, machine.ini, Smc), Database/Website Releases, protections (JGuard, wFilter, STFilter), section « Protection & Exploit vSRO »
- **Fiabilité** : ★★★★

### Wikis de serveurs privés (officiel republié + custom)

#### ExaySRO Wiki
- **URL** : https://wiki.exaysro.com
- **Description** : wiki d'un serveur à public arabe (cap 130 + Reborn) — la table HP des uniques y est **identique au client officiel** (Tiger Girl 598 720 … Apis 21 068 995), et le guide Job Temple a été corrigé par le GM (horaires exacts des salles) : exemple type du mélange [OFFICIEL-DÉRIVÉ] / [CUSTOM] caractéristique des wikis de privés
- **Fiabilité** : ★★★★ (valeurs officielles republiées) / ★★★ (custom serveur)

### Outillage data mining (PK2 / SQL / packets)

#### SRO Archive Explorer (2025)
- **URL** : https://www.elitepvpers.com/forum/sro-pserver-guides-releases/5364960-release-sro-archive-explorer-pk2-browser-3d-model-map-effect-viewer-skill-brows.html
- **Description** : navigateur PK2 + viewer 3D (modèles, cartes, effets) + navigateur de skills — l'outil d'inspection de client le plus complet actuellement (publié le 06/12/2025, actif en 2026) pour explorer un client sans tout extraire
- **Fiabilité** : ★★★★

#### pk2 / pk2_mate (Rust)
- **URL** : https://github.com/veykril/pk2
- **Description** : crate Rust de lecture/écriture PK2 + CLI `pk2_mate extract/pack/list` — la voie moderne pour extraire `itemdata.txt`/`skilldata.txt`/`characterdata.txt` d'un client (utilisée par OpenSilkroadMap) ; alternative C# : [SRO.PK2API de JellyBitz](https://github.com/JellyBitz/SRO.PK2API)
- **Fiabilité** : ★★★★

#### SilkroadDoc (rappel)
- **URL** : https://github.com/DummkopfOfHachtenduden/SilkroadDoc
- **Description** : LA documentation de référence des formats de fichiers et packets (basée vSRO 1.188) — ⚠️ repo archivé en lecture seule le 01/06/2025, le contenu vit dans le [wiki « Silkroad Security »](https://github-wiki-see.page/m/DummkopfOfHachtenduden/SilkroadDoc/wiki/Silkroad-Security) (handshake, chiffrement)
- **Fiabilité** : ★★★★★

#### Ducksoup — schémas SQL vSRO 1.188
- **URL** : https://github.com/ducksoup-sro/ducksoup/tree/main/Database/VSRO188
- **Description** : schémas complets des ~200 tables SQL de la shard vSRO 1.188 (SRO_VT_SHARD/ACCOUNT/LOG), inspectés via API GitHub — `_RefObjChar` (HP/niveaux des monstres), `_RefMagicOptByItemOptLevel` (plages de blues par degré), `Tab_RefNest` (nids de spawn), `_RefLevel` (XP/niveau), `_RefQuest*` (quêtes)
- **Fiabilité** : ★★★★★

#### SROquests — quêtes extraites des files
- **URL** : https://github.com/AlighieriDemiurgs/SROquests
- **Description** : **280+ quêtes extraites des files vSRO v1.188** (rates 1x), assemblé en 2026 : NPC donneur, niveaux, récompenses exactes, répétitions, coordonnées
- **Fiabilité** : ★★★★

#### RSBot (open source) & API phBot
- **RSBot** : https://github.com/SDClowen/RSBot — bot C# open source (GPLv3/AGPL-3) dont les **handlers de packets** (spawn de monstres, stats d'items, drops) constituent des structures de données prêtes à l'emploi pour récolter HP/niveaux/drops sur n'importe quel serveur (supporte iSRO, kSRO, vSRO 188/193/274, BlackRogue 100/110, TRSRO, ruSRO…)
- **API plugins phBot** : https://plugins.phbot.org/phbot-api — `get_drops()`, `get_inventory()`, `log()` ; plugin « Unique Spawn Logging » (opcode 0x300C, base des trackers) : https://forum.projecthax.com/t/unique-spawn-logging/5280
- **Fiabilité** : ★★★★★ (structures RSBot) / ★★★★ (API phBot)
