## 📊 Skill Costs Summary

### SP Costs per Mastery Level

**Total SP to Max Mastery (Level 120):**
- **Approximately:** 8,400,000 SP (120 SP per skill point x 70 skill points)
- **Per skill book:** ~120,000 SP (1,000 SP x 120 levels)

### Recommended Progression

**Level 1-40:** Focus 1 mastery
**Level 40-60:** Add 2nd mastery (element)
**Level 60-80:** Add 3rd mastery (element)
**Level 80+:** Max all
