## 🎯 Guide d'Optimisation

### Stratégies d'Équipement par Niveau

#### Niveau 1-40 (Débutant)

- **Armes** : 1D-3D (épée, arc, bâton)
- **Armure** : Set basique (armure légère/medium)
- **Bijoux** : Anneaux +1-+3
- **Budget** : 10,000-50,000 gold
- **Priorité** : Survie et apprentissage

#### Niveau 40-70 (Intermédiaire)

- **Armes** : 4D-6D (épée+, lance, arc+)
- **Armure** : Set moyen (armure medium/lourde)
- **Bijoux** : Anneaux +4-+6
- **Budget** : 50,000-500,000 gold
- **Priorité** : Équilibre DPS/défense

#### Niveau 70-100 (Avancé)

- **Armes** : 7D-9D (lance+, arc++, bâton+)
- **Armure** : Set rare (armure lourde/unique)
- **Bijoux** : Anneaux +7-+9
- **Budget** : 500,000-5,000,000 gold
- **Priorité** : Spécialisation (PvP ou PvE)

#### Niveau 100+ (Expert)

- **Armes** : 10D-13D (uniques, légendaires)
- **Armure** : Set unique/légendaire
- **Bijoux** : Anneaux +10-+12
- **Budget** : 5,000,000+ gold
- **Priorité** : Optimisation maximale

## ❓ FAQ

### Questions Fréquentes sur les Items

**Q: Quel est le meilleur équipement pour débuter ?**
R: Un set 3D complet avec une arme 3D+3 offre un excellent rapport qualité-prix pour les niveaux 1-40. Concentrez-vous sur l'équilibre plutôt que sur un item spécifique.

**Q: Comment obtenir des items 13D ?**
R: Les items 13D sont extrêmement rares et peuvent être obtenus via :
- Drop de boss uniques (0.01% de chance)
- Événements spéciaux (ex: Événement du Dragon)
- Échange contre des items légendaires + ressources
- Crafting avancé (nécessite niveau 110+)

**Q: Vaut-il la peine d'enhancer des items +10+ ?**
R: Oui, mais seulement si vous avez un budget important. Les items +10+ offrent des bonus significatifs (20-30% d'augmentation), mais le risque de destruction est élevé (30-50%). Utilisez toujours des scrolls de protection.

**Q: Où trouver les meilleurs items pour mon niveau ?**
R: Plusieurs options :
- **Stall Network** : [23_STALL_NETWORK.md](23_STALL_NETWORK.md) pour les items players
- **NPCs Vendeurs** : Items basiques dans les villes
- **Farming** : Monstres de votre niveau +5 à +10
- **Quêtes** : Récompenses spécifiques

**Q: Comment réparer mes items efficacement ?**
R: Méthodes de réparation :
- **NPCs de réparation** : Dans toutes les grandes villes (coût : 1-5% de la valeur)
- **Scrolls de réparation** : Achetable ou craftable (réparation 100%)
- **Compétence d'alchimie** : Si vous êtes alchimiste (niveau 50+ requis)

**Q: Quelle est la différence entre les items chinois et européens ?**
R: Les items sont universels, mais certaines classes ont des préférences :
- **Chinois** : Préfèrent les armes légères et rapides (épées courtes, arcs)
- **Européens** : Préfèrent les armes lourdes (épées longues, haches, masses)

**Q: Comment choisir entre armure lourde et légère ?**
R: Dépend de votre style de jeu :
- **Lourde** : Meilleure défense, moins de mobilité (idéal pour tanks, PvP)
- **Légère** : Meilleure mobilité, moins de défense (idéal pour DPS, farming)
- **Medium** : Équilibre parfait pour la plupart des situations

## 💻 Implémentation Technique

### Database Schema (SRObro)

```typescript
// Prisma schema pour les items
model Item {
  id          String   @id
  name        String
  degree      Int      // 1-13
  type        ItemType
  subType     ItemSubType?
  rarity      ItemRarity // NORMAL, RARE, SOS, SOM, SOSUN
  stats       ItemStats?
  price       ItemPrice
  description String?
  required    RequiredStats?
  icon        String?
  mesh        String?  // 3D mesh reference
}

enum ItemType {
  WEAPON
  ARMOR
  ACCESSORY
  CONSUMABLE
  MATERIAL
  SPECIAL
}

enum ItemSubType {
  // Weapons
  SWORD, BLADE, SPEAR, GLAIVE, BOW, XDAGGER, XBOW, STAFF, DAGGER, HARP, AXE
  // Armor
  HELMET, CHEST, SHOULDERS, LEGS, BOOTS, GLOVES
  // Accessory
  RING, EARRING, NECKLACE
  // Consumable
  POTION, ELIXIR, SCROLL, PILLS
}

enum ItemRarity {
  NORMAL
  RARE
  SOS    // Seal of Star
  SOM    // Seal of Moon
  SOSUN  // Seal of Sun
}

model ItemStats {
  id              String   @id
  itemId          String   @unique
  item            Item     @relation(fields: [itemId], references: [id])
  phyAtk          Int?
  magAtk          Int?
  phyDef          Int?
  magDef          Int?
  hp              Int?
  mp              Int?
  critRate        Int?
  critDamage      Int?
  parryRatio      Int?
  attackRating    Int?
}

model ItemPrice {
  id              String   @id
  itemId          String   @unique
  item            Item     @relation(fields: [itemId], references: [id])
  npcPrice        Int
  stallPrice      Int?
}

model RequiredStats {
  id              String   @id
  itemId          String   @unique
  item            Item     @relation(fields: [itemId], references: [id])
  level           Int
  str             Int?
  int             Int?
}
```
