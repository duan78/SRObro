## 📝 Notes d'usage

- **Objectif** : référence visuelle pour le développement de **SRObro** (HUD, villes, monstres, interface, effets, ambiance graphique de l'ère 2005-2015).
- **Droits** : toutes ces images appartiennent à **Joymax / Silkroad Online** (captures joueur, artworks officiels, miniatures YouTube). **Usage interne uniquement** — ne pas redistribuer ni publier.
- **Formats** : les images du CDN Fandom sont servies en **WebP** (qualité préservée) ; les miniatures YouTube sont en JPEG (le plus souvent 1280×720).
- **Miniatures YouTube** : elles montrent une image-clé réelle de gameplay, pratique comme référence rapide ; la vidéo source est indiquée pour aller plus loin.
- **Fiabilité du contenu** : les fichiers issus de wikis (Fandom silkroad/zszc) reflètent le jeu classique ; quelques miniatures proviennent de serveurs privés récents (fidelity visuelle globale bonne, détails d'UI pouvant varier).
- ⚠️ Les fichiers `zones_carte_region_*` et `classes_gameplay2004_*` n'ont pas pu être vérifiés visuellement (contenu supposé d'après leur page source wiki / galerie 2004).
