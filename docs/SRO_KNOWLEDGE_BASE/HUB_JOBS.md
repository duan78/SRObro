## 🎯 Introduction

Ce **hub centralise toutes les informations sur le système de jobs** de Silkroad Online. Le triangle Trader/Thief/Hunter est l'un des aspects les plus uniques et excitants du jeu.

### Points Clés
- 🔄 **Triangle d'équilibre** : Trader ↔ Thief ↔ Hunter
- 💰 **Commerce lucratif** : Profit énorme pour les traders
- ⚔️ **PvP excitant** : Vols de caravanes et protection
- 🤝 **Joueur vs Joueur** : Interactions sociales fortes
- 📈 **Progression** : Levels et rewards uniques

### Les 3 Jobs
| Job | Rôle | Style | Profit |
|-----|------|-------|---------|
| **Trader** | Commerce | Transporter marchandises | ⭐⭐⭐⭐⭐ |
| **Thief** | Voleur | Attaquer caravanes | ⭐⭐⭐⭐ |
| **Hunter** | Protecteur | Défendre caravanes | ⭐⭐⭐ |

## 🔄 Système de Jobs

### Guide Principal
👉 **[09_JOB_SYSTEM_OVERVIEW.md](09_JOB_SYSTEM_OVERVIEW.md)** - Vue d'ensemble complète

### Vue d'Ensemble

#### Le Triangle d'Équilibre
```
        TRADER
       /        \
      /          \
  Hunter          Thief
      \          /
       \        /
        Économie
```

#### Comment ça marche
1. **Trader** achète des marchandises dans une ville
2. **Trader** transporte vers une autre ville (à pied/cheval)
3. **Thief** attaque la caravane pour voler les marchandises
4. **Hunter** défend la caravane contre les thieves

### Rejoindre un Job

#### Traders
- **NPC** : Trader Union à Jangan, Donwhang, Hotan, Alexandria
- **Level requis** : 20+
- **Coût** : 10,000 gold
- **Équipement** : Camel (2 slot) ou plus

#### Thieves
- **NPC** : Thief Union à Jangan, Donwhang, Hotan, Alexandria
- **Level requis** : 20+
- **Coût** : 10,000 gold
- **Special** : Peut attaquer les caravanes

#### Hunters
- **NPC** : Hunter Union à Jangan, Donwhang, Hotan, Alexandria
- **Level requis** : 20+
- **Coût** : 10,000 gold
- **Reward** : Gold pour chaque trader escorté

### Job Points et Rewards

#### Trader Points
- **1 étoile** : 1,000 points
- **2 étoiles** : 10,000 points
- **3 étoiles** : 100,000 points
- **Rewards** : Équipement unique, titres, buffs

#### Thief Points
- **Points par kill** : Variable selon level trader
- **Bonus unique** : Plus de points = plus de loot
- **Rewards** : Équipement thief, thief suit

#### Hunter Points
- **Points par trader** : 1,000+ par escort réussi
- **Bonus kill** : Points pour thieves tués
- **Rewards** : Hunter suit, équipement, buffs

### Guide Principal
👉 **[10_TRADER_GUIDE.md](10_TRADER_GUIDE.md)** - Guide complet Trader

### Vue d'Ensemble

#### Objectif
Acheter des marchandises dans une ville, les transporter vers une autre ville, et vendre pour un profit.

#### Profit Potentiel
| Route | Distance | Profit | Danger |
|-------|----------|--------|--------|
| Jangan ↔ Donwhang | Court | ~100k | Bas |
| Donwhang ↔ Hotan | Moyen | ~300k | Moyen |
| Hotan ↔ Alexandria | Long | ~1M | Haut |

### Marchandises

#### Jangan → Donwhang
| Marchandise | Achat | Vente | Profit |
|-------------|-------|-------|--------|
| Potions | 50k | 80k | +60% |
| Armes 3D | 100k | 150k | +50% |
| Armor 3D | 120k | 180k | +50% |

#### Hotan → Alexandria
| Marchandise | Achat | Vente | Profit |
|-------------|-------|-------|--------|
| Épices | 300k | 800k | +166% |
| Soie | 250k | 600k | +140% |
| Tapis | 200k | 500k | +150% |

### Stratégies Trader

#### 1. Choix du Transport
- **Camel (2 slot)** : Level 1-30
- **Camel (3 slot)** : Level 30-50
- **Ouest (3 slot)** : Level 50+
- **Transporte_npc** : 5+ slot, level 80+

#### 2. Timing
- **Heures creuses** : Moins de thieves
- **Week-end** : Plus de hunters disponibles
- **Events job** : Bonus rewards

#### 3. Routes
- **1 étoile** : Routes sûres, moins de profit
- **2 étoiles** : Équilibre profit/risque
- **3 étoiles** : Maximum profit, maximum risque

## ⚔️ Guide Thief

### Guide Principal
👉 **[11_THIEF_GUIDE.md](11_THIEF_GUIDE.md)** - Guide complet Thief

### Vue d'Ensemble

#### Objectif
Attaquer les caravanes traders, voler les marchandises, et les revendre ou les utiliser vous-même.

#### Playstyle
- **Agressif** : Attaquer les caravanes
- **Stealth** : Se cacher, embuscade
- **PvP focus** : Combat contre hunters et traders
- **Solo ou groupe** : Plus efficace en groupe

### Techniques de Vol

#### 1. Scout
- Observer les routes
- Identifier les caravanes vulnérables
- Repérer les hunters

#### 2. Ambush
- Se cacher près des points de passage
- Attendre la caravane
- Attaquer par surprise

#### 3. Kill & Loot
- Tuer le trader ou transport
- Loot la marchandise
- Escape rapide

#### 4. Sell or Keep
- **Vendre** : Profit immédiat
- **Garder** : Utiliser soi-même
- **Partager** : En groupe

### Meilleurs Spots

#### Jangan-Donwhang Road
- **Coords** : X: 1200-1500, Y: 1400-1700
- **Level caravanes** : 20-40
- **Danger** : Hunters fréquents

#### Hotan Desert
- **Coords** : X: 2500-3200, Y: 2800-3500
- **Level caravanes** : 40-70
- **Danger** : Moyen

#### Alexandria Roads
- **Coords** : X: -500 à 500, Y: -100 à 100
- **Level caravanes** : 70-110
- **Danger** : Élevé

## 🛡️ Guide Hunter

### Guide Principal
👉 **[12_HUNTER_GUIDE.md](12_HUNTER_GUIDE.md)** - Guide complet Hunter

### Vue d'Ensemble

#### Objectif
Protéger les caravanes traders contre les thieves et earning des rewards pour chaque escort réussi.

#### Playstyle
- **Protecteur** : Défendre les traders
- **PvP défensif** : Combat contre thieves
- **Support** : Buffs et heals
- **Solo ou groupe** : Plus efficace en groupe

### Rewards

#### Paiement par Trader
- **1 étoile** : 50,000 gold
- **2 étoiles** : 100,000 gold
- **3 étoiles** : 200,000 gold

#### Bonus Kills
- **Thief kill** : 10,000 gold + points
- **Assist** : 5,000 gold + points

### Techniques de Protection

#### 1. Scout Ahead
- Avancer de la caravane
- Repérer les thieves
- Signaler les dangers

#### 2. Formation
- **Front** : Melee fighters
- **Middle** : Traders et transports
- **Back** : Ranged et healers

#### 3. Response
- **Thief spotted** : Intercepter avant d'attaquer
- **Under attack** : Protéger le transport
- **Thief dead** : Continuer l'escort

#### 4. Communication
- Partie vocal recommandée
- Signaux visuels
- Coordination avec trader

### Meilleures Routes

#### Jangan-Donwhang (Débutants)
- **Level** : 20-40
- **Danger** : Bas
- **Pay** : 50k-100k par run

#### Hotan-Alexandria (Avancés)
- **Level** : 70-110
- **Danger** : Haut
- **Pay** : 150k-300k par run

#### Thief Team (5 personnes)
| Rôle | Classe | Job |
|------|--------|-----|
| **Lead** | Rogue/Cleric | Thief |
| **Crowd Control** | Warlock/Bard | Thief |
| **Burst DPS** | Wizard/Thief | Thief |
| **Tank** | Warrior | Thief |
| **Support** | Cleric | Thief |

### Communication

#### Signaux Vocaux
- **"Thief at X coords!"** : Thief repéré
- **"Protect trader!"** : Trader attaqué
- **"Clear!"** : Zone sécurisée
- **"Run!"** : Fuir si nécessaire

#### Strategies
- **Focus fire** : Tous sur une cible
- **Peel** : Protéger le trader
- **Kite** : Attirer les thieves loin
- **Bait** : Trader comme appât

### Profit par Job

#### Trader (le plus lucratif)
- **1 étoile** : ~100k profit/run
- **2 étoiles** : ~300k profit/run
- **3 étoiles** : ~1M profit/run
- **Run time** : 20-60 minutes
- **Profit/heure** : 100k-3M/heure

#### Thief
- **Level 20-40** : ~50k-100k/heure
- **Level 40-70** : ~200k-500k/heure
- **Level 70-110** : ~500k-2M/heure
- **Variable** : Dépend des caravanes

#### Hunter (le plus stable)
- **1 étoile** : 50k/run + 10k/kill
- **2 étoiles** : 100k/run + 20k/kill
- **3 étoiles** : 200k/run + 50k/kill
- **Stable** : Revenus réguliers

### Investissements

#### Équipement Trader
- **Camel 2 slot** : 500k gold
- **Camel 3 slot** : 2M gold
- **Transport 5 slot** : 50M+ gold
- **Return scroll** : 100k chacun

#### Équipement Thief
- **Thief suit** : +10% thief speed
- **Stealth pots** : 50k chacun
- **Transport** : Pour loot

#### Équipement Hunter
- **Hunter suit** : +5% exp/job rewards
- **Arme +7** : Pour tuer thieves vite
- **HP set** : Pour survivre

## 💻 Implémentation Technique

### Système de Jobs pour SRObro

#### Database Schema
```sql
-- From DEVELOPMENT_TECHNICAL_GUIDE.md
CREATE TABLE job_characters (
  id SERIAL PRIMARY KEY,
  character_id INTEGER REFERENCES characters(id),
  job_type VARCHAR(10), -- 'TRADER', 'THIEF', 'HUNTER'
  job_level INTEGER DEFAULT 1,
  job_points INTEGER DEFAULT 0,
  current_run_id INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE job_runs (
  id SERIAL PRIMARY KEY,
  trader_id INTEGER REFERENCES job_characters(id),
  start_city VARCHAR(50),
  end_city VARCHAR(50),
  star_level INTEGER, -- 1, 2, 3
  status VARCHAR(20), -- 'ACTIVE', 'SUCCESS', 'FAILED'
  profit INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);
```
