## 📚 Introduction

Le **Stall Network** est le système de marché joueur-à-joueur de Silkroad Online. Il permet aux joueurs de créer des boutiques personnelles (stalls) pour vendre leurs items à d'autres joueurs.

### Points Clés
- **Vendre 24h/24** même quand déconnecté
- **Accès via Stall Network** (menu de jeu)
- **Emplacements limités** dans les villes
- **Économie joueur-driven**

---

## 🏪 Créer un Stall

### Comment Ouvrir un Stall

```
1. Aller dans une ville avec des emplacements de stall
2. Trouver un emplacement libre (marqué "EMPTY")
3. Faire clic droit sur l'emplacement
4. Sélectionner "Open Stall"
5. Donner un titre au stall
6. Définir les prix des items
7. Confirmer
```

### Interface du Stall

```
┌─────────────────────────────────────┐
│ Stall Title: [Your Title Here]       │
│                                      │
│ Item List:                           │
│ ┌─────────────────────────────────┐ │
│ │ [Icon] Sword 9D +5           │ │
│ │ Price: 5,000,000            │ │
│ │ [Edit] [Remove]              │ │
│ └─────────────────────────────────┘ │
│                                      │
│ [Add Item] [Set Title] [Close]       │
└─────────────────────────────────────┘
```

### Restrictions

- **Level requis:** Aucun (même level 1 peut ouvrir un stall)
- **Coût:** Gratuit
- **Durée:** Permanent jusqu'à fermeture
- **Items limite:** Variable (selon le serveur)
- **Prix minimum:** 1 gold

### Fonctionnalités

#### Recherche et Filtrage

```
Options de recherche:
  - Par nom d'item
  - Par type d'item (Weapon, Armor, etc.)
  - Par degree (1D-13D)
  - Par prix (min-max)
  - Par SOX (Seal of Star/Moon/Sun)

Filtres:
  - Weapons seulement
  - Armor seulement
  - Accessories seulement
  - SOX seulement
```

```
Pour chaque item dans un stall:
  - Icone de l'item
  - Nom (+stats si identifié)
  - Prix demandé
  - Durée d'affichage (optionnel)
  - Nom du vendeur
  - Rating du vendeur (si système de notation)

Identification:
  - Les items non-identifiés montrent "??"
  - Doivent être identifiés avant d'acheter
```

## 💰 Stratégies de Vente

### quoi Vendre?

#### High-Value Items (Profit Élevé)

```
SOX Items (Seal Equipment):
  - Seal of Star (SOS): 2-5x prix normal
  - Seal of Moon (SOM): 5-10x prix normal
  - Seal of Sun (SOSun): 20-50x prix normal

Exemple:
  - Sword 9D normal: 500,000 gold
  - Sword 9D SOS: 2,000,000-5,000,000 gold
  - Sword 9D SOM: 5,000,000-10,000,000 gold
  - Sword 9D SUN: 20,000,000+ gold
```

#### Équipement 10D-13D (End-Game)

```
Weapons 10D+:
  - Forte demande
  - Prix: 1M-10M selon stats
  - +5 ou +10 items vendent plus cher

Armor 10D+:
  - Sets complets vendent mieux
  - Critiques importantes:
    * Phy DEF vs Mag DEF
    * Blues (STR/INT) très prisées
    * Durabilité > 90%

Accessories:
  - Rings avec +5 stats
  - Necklaces avec phy/mag atk %
  - Earrings avec crit %
```

#### Matériaux et Consommables

```
Alchemy Materials:
  - Elixirs (Weapon/Armor/Accessory)
  - Lucky Powders (par degree)
  - Stones (Weapon/Armor/Accessory)

Potions:
  - Pas très rentable en général
  - Sauf en gros volumes

Quest Items:
  - Certains items de quête (rares)
  - Monster drops (materials)
```

### Stratégies de Prix

#### Recherche de Prix

```
1. Vérifier les stalls concurrents
2. Noter les prix moyens
3. Ajuster votre prix:
   - -10% pour vendre vite
   - Prix du marché pour vente normale
   - +10-20% si item rare/strong
```

#### Psychological Pricing

```
Prix se terminant par:
  - 999,999 (semble moins cher que 1,000,000)
  - 499,999 (semble moins cher que 500,000)
  - 9,999 (semble moins cher que 10,000)

Exemple:
  - 1,000,000 gold
  - 999,999 gold (semble moins cher!)

Cette tactique fonctionne très bien.
```

#### Bundling (Lots)

```
Grouper des items:
  - Set armor complet (discount sur le lot)
  - Weapon + Shield (+5 ensemble)
  - Materials en gros (100x à prix réduit)

Avantages:
  - Écoule plus vite
  - Meilleur profit global
  - Attracte les acheteurs looking for sets
```

### Timing de Vente

```
Meilleurs moments pour vendre:

1. Après events (Fortress War, Uniques morts)
   - Beaucoup de gold en circulation
   - Joueurs veulent upgrader leur gear

2. Week-ends
   - Plus de joueurs connectés
   - Plus d'acheteurs potentiels

3. Nouveau content (level cap increase)
   - Demande pour nouveaux degrees
   - Joueurs veulent se reroll

4. Server restart
   - Prix souvent instables
   - Opportunités d'arbitrage
```

## 💡 Conseils pour Réussir

### Optimiser votre Titre de Stall

```
Mauvais exemples:
  ❌ "My stall" (Pas informatif)
  ❌ "Selling stuff" (Trop vague)
  ❌ " ITEMS" (Confusing)

Bons exemples:
  ✅ "SOS 9D WEAPONS - CHEAP!"
  ✅ "10D Armor Sets +5 STR"
  ✅ "SOM 7D Sword - 5M"
  ✅ "Elixirs & Stones - Best Prices"
```

### Description des Items

```
Toujours inclure les stats importantes:

Weapons:
  - Attack range (min-max)
  - Crit rate
  - Attack speed
  - Blues (+STR, +INT, etc.)

Armor:
  - Phy DEF
  - Mag DEF
  - Block/Parry rate
  - Blues

Accessories:
  - Stats (+5 STR, +3% crit, etc.)
```

### Gestion de l'Inventaire

```
1. Utiliser les storage tabs
   - Un tab pour items à vendre
   - Un tab pour items personnels

2. Organiser par catégorie
   - Weapons ensemble
   - Armor ensemble
   - Accessoires ensemble

3. Garder des stocks
   - Items populaires en quantité
   - Rotation des items rares
```

### Service Client

```
Si quelqu'un vous envoie un message:

Répondre rapidement:
  ✅ "Negotiable?" → "Yes, make offer!"
  ✅ "Is this +5?" → List all stats
  ✅ "Can you lower price?" → Consider!

Ignorer:
  ❌ "Is this legit?" (Trolls)
  ❌ "Too expensive!" (Sans offre)
  ❌ Spam
```

### Scams à Éviter (Acheteurs)

```
Signes de scam:
  ⚠️ Prix trop beau pour être vrai
  ⚠️ "Trust trade" (Donner d'abord)
  ⚠️ Item switch au dernier moment
  ⚠️ Refus d'utiliser Stall Network

Toujours:
  ✅ Vérifier l'item avant d'acheter
  ✅ Utiliser Stall Network (sûr)
  ✅ Chater avant si gros achat
  ✅ Screenshots comme preuve
```

## 🎯 Exemples de Stalls Réussis

### Exemple 1: SOS 9D Weapons

```
Title: "★SOS 9D WEAPONS★ +5 CHEAP!"

Items:
  - Sword 9D SOS +5 [CRIT+7] → 8,500,000
  - Blade 9D SOS +5 [ATK+70%] → 7,000,000
  - Spear 9D SOS +5 [PHY+10] → 6,000,000

Stratégie:
  - Prix légèrement en-dessous du marché
  - Items forts (crit +5 et au-delà)
  - Titre accrocheur avec étoiles

Résultat:
  - Tout vendu en 48h
  - Profit total: ~30M gold
```

### Exemple 2: 10D Armor Sets

```
Title: "10D SET +5 STR - FULL SET"

Items:
  - Armor 10D +5 STR +9 [HEAD]
  - Armor 10D +5 STR +8 [CHEST]
  - Armor 10D +5 STR +9 [SHOULDER]
  - Armor 10D +5 STR +8 [LEGS]

  - Armor 10D +5 STR +7 [GLOVES]

Bundle Price:
  - Complet: 25,000,000 (10% discount)
  - Pièces séparées: Prix listé

Stratégie:
  - Encourage l'achat du set complet
  - Discount pour le lot
  - Tous les items sont +5 STR (très fort)

Résultat:
  - 3 sets complets vendus
  - Quelques pièces séparées vendues
  - Profit total: ~50M gold
```

### Exemple 3: Materials Bulk

```
Title: "BULK ELIXIRS 10D - CHEAPEST!"

  - Weapon Elixir 10D ×50 → 4M each (2M total)

Stratégie:

  - Cible les alchemists

  - Vendu en masse à 2 joueurs
  - Profit: ~10M gold
```

## 🚫 Erreurs à Éviter

### Erreurs de Prix

```
❌ Prixer trop bas:
  - Perdre de la valeur
  - "Vendre" soi-disant mais perdre du profit
  - Crasher le marché

❌ Prixer trop haut:
  - Jamais vendre
  - Payer des frais de stall inutilement
  - Perdre des ventes aux concurrents

✅ Stratégie gagnante:
  - Rechercher les prix du marché
  - Prixer compétitivement
  - Ajuster régulièrement
```

### Erreurs de Présentation

```
❌ Titre non-descriptif:
  - "My stall"
  - "Selling items"
  - "Stall 1"

❌ Missing stats importants:
  - Pas de crit rate
  - Pas de blues (stats)
  - Pas de degree

✅ Bonne présentation:
  - Titre informatif avec items clés
  - TOUJOURS lister les stats importantes
  - Être prêt à négocier
```

### Erreurs de Timing

```
❌ Ouvrir pendant events majeurs:
  - Fort Fort War (personnes déconnectées)
  - Maintenance serveur
  - Server restart

❌ Laisser un stall trop longtemps sans mise à jour:
  - Prix dépassés
  - Items vendus épuisés
  - Perte de clients réguliers

✅ Bon timing:
  - Vendre après events (quand les gens ont gold)
  - Mettre à jour les prix régulièrement
  - Adapter au marché actuel
```

## 📈 Astuces Avancées

### Market Manipulation (Avertissement)

```
⚠️ CERTAINS SERVEURS INTERDISENT CECI:

1. Cornering the Market:
   - Acheter TOUS les items d'un type
   - Revendre à prix plus élevé
   - Risque: Si ça ne marche pas, perte massive

2. False Scarcity:
   - Prétendre qu'un item est rare
   - Vendre beaucoup plus cher
   - Risque: Perte de réputation

3. Bid Shilling:
   - Faire des offres très basses
   - Acheter à des joueurs ignorants
   - Risque: Banni sur certains serveurs

✅ Pratique légitime:
  - Acheter quand prix bas
   - Stocker items
   - Vendre quand prix monte
   - Arbitrage entre villes
```

### Sniping (Achat rapide)

```
Technique:
  1. Refresh le Stall Network régulièrement
  2. Repérer les items sous-évalués
  3. Acheter immédiatement
  4. Revendre à prix juste

Outils:
  - Connexion rapide
  - Gold disponible
  - Connaissance des prix

Items à sniper:
  - SOX mal évalués (souvent +0-1 vendus comme normaux)
  - Sets complets vendus par morceaux
  - Items avec stats forts non identifiés
```

### Stall Hopping

```
Stratégie:
  1. Parcourir tous les stalls d'une ville
  2. Noter les sous-évaluations
  3. Acheter et revendre

Villes les plus rentables:
  - Hotan (gros volume)
  - Alexandria (items chers)
  - Samarkand (pics de prix)

Fréquence:
  - 1-2 fois par jour
  - Juste après events
  - Pendant la nuit (moins de concurrence)
```
