## 🎯 Introduction

Le **PvP (Player versus Player)** est l'aspect le plus compétitif de Silkroad Online. Choisir le bon build est essentiel pour dominer les adversaires en 1v1, en Fortress War, ou lors des events PvP.

### Points Clés
- ✅ **Pure STR** : Dégâts physiques énormes, beaucoup d'HP
- ✅ **Pure INT** : Dégâts magiques dévastateurs, beaucoup de MP
- ✅ **Hybrid** : Équilibre, généralement moins optimal en PvP pur
- ✅ **Support** : Cleric/Bard pour les buffs et heals
- ✅ **Cap** : Les builds varient selon le level cap (80, 90, 100, 110, 120, 130, 140)

## 🏆 Tier List PvP 1v1

### S-Tier (Dominants) - Les Meilleurs Builds

#### 1. Warrior/Cleric (Pure STR)
**Le "Bread and Butter" des builds PvP**

- **Masteries** : Warrior 110 / Cleric 110
- **Type** : Pure STR
- **Armor** : Armor ou Protector (HP+++, PHY DEF++)
- **Weapon** : 2H Sword/Axe + Shield
- **Pourquoi S-Tier** :
  - ✅ **Survit à tout** avec les heals cleric
  - ✅ **Dégâts énormes** en 2H
  - ✅ **Defense buff** (Guard Buff) quasi-immortel
  - ✅ **Shield** pour bloquer les attaques
  - ✅ **Facile à jouer** - pardonnable

**Playstyle** :
- Tank les dégâts pendant que vous heal
- Attendre que l'ennemi soit OOM (out of mana)
- Burst avec 2H skills quand il est vulnérable

#### 2. Rogue/Cleric (Pure STR)
**Le plus grand burst physique du jeu**

- **Masteries** : Rogue 110 / Cleric 110
- **Type** : Pure STR
- **Armor** : Protector ou Garment (speed++)
- **Weapon** : Dual Daggers (Xbow pour switch)
- **Pourquoi S-Tier** :
  - ✅ **Dégâts critiques énormes** (15k+ crits)
  - ✅ **Stealth** pour l'élément de surprise
  - ✅ **Knockdowns** en chaîne
  - ✅ **Heals** pour la survie
  - ❌ **Difficile à maîtriser** - haut skill ceiling

**Playstyle** :
- Stealth → Knockdown → Full burst
- Si l'ennemi survive → Stealth et repeat
- Swap en Xbow pour finishing blows

### A-Tier (Très Forts)

#### 3. Warlock/Cleric (Pure INT)
**Le maître des debuffs**

- **Masteries** : Warlock 110 / Cleric 110
- **Type** : Pure INT
- **Armor** : Garment (MAG DEF++, speed++)
- **Weapon** : Staff
- **Pourquoi A-Tier** :
  - ✅ **Debuffs dévastateurs** ( -50% defense, etc.)
  - ✅ **DoT (Damage over Time)** énormes
  - ✅ **Crowd control** avec sleep/roots
  - ✅ **Heals** pour survivre
  - ❌ **Requiert beaucoup de skill**

**Playstyle** :
- Appliquer tous les debuffs sur l'ennemi
- Laisser les DoT faire le travail
- Kiter pendant que l'ennemi meurt lentement

#### 4. Wizard/Warrior (Pure INT)
**"Le meilleur build de tous les temps" selon certains**

- **Masteries** : Wizard 110 / Warrior 110
- **Type** : Pure INT
- **Armor** : Garment
- **Weapon** : Staff
- **Pourquoi A-Tier** :
  - ✅ **AOE massives** pour PvP groupé
  - ✅ **Dégâts magiques énormes**
  - ✅ **Defense buffs** du warrior
  - ✅ **Très polyvalent**

**Playstyle** :
- Nuker de loin avec les spells wizard
- Utiliser warrior buffs pour la défense
- Perfect pour battle arena et fortress

### B-Tier (Solides)

#### 5. Warrior/Rogue (Pure STR)
**Combat rapide et réactif**

- **Masteries** : Warrior 110 / Rogue 110
- **Type** : Pure STR
- **Armor** : Armor
- **Weapon** : 2H Sword/Axe + Shield (swap)
- **Pourquoi B-Tier** :
  - ✅ **Dégâts solides**
  - ✅ **Bonnes utilités** (knockdowns, stuns)
  - ✅ **Bonnes stats défensives**
  - ❌ **Manque de heals**

**Playstyle** :
- Jouer comme un Warrior/Cleric mais plus offensif
- Utiliser les stuns rogue pour interrompre les skills ennemies

## ⚔️ Stratégies PvP

### Généralités

#### Positionnement
- **Toujours bouger** : Jamais stay still
- **Kiter** : Hit and run pour les INT
- **Face check** : Regarder vers l'ennemi pour parry

#### Buff Management
- **Pre-buff** : Tous les buffs avant le fight
- **Buff timing** : Refresh les buffs critiques (Guard, etc.)
- **Debuff purge** : Cleric/Warlock pour enlever les debuffs

#### Potion Usage
- **HP Potions** : Utiliser à 50% HP, pas attendre 10%
- **MP Potions** : Critique pour les nukers
- **Vigor Pills** : Instant 50% HP (cooldown 5s)
- **Universal Pills** : 50% HP + 50% MP

### Stratégies par Build

#### Warrior/Cleric Strategy

**Phase 1: Opening**
1. Appliquer **Bless Spell** (+30% PHY DEF)
2. Appliquer **Guard Buff** (+50% PHY DEF)
3. Commencer avec **2H Flying Dragon**

**Phase 2: Mid-Fight**
4. Si HP < 70%, **Healing Cycle**
5. Continuer à 2H attack
6. **Chain Crash** si l'ennemi essaye de kite

**Phase 3: Finish**
7. Quand l'ennemi est OOM (out of mana), **Full Burst**
8. 2H skills jusqu'à mort

**Tips** :
- ✅ **Ne jamais paniquer** avec les heals
- ✅ **Attendre OOM ennemi** avant de burst
- ✅ **Switch Shield** si focus

#### Rogue/Cleric Strategy

**Phase 1: Opening**
1. **Stealth** (invisible)
2. Positionner derrière l'ennemi
3. **Knockdown Arrow** (Xbow)

**Phase 2: Burst Window**
4. Pendant le KD, **Dual Dagger Attack**
5. **Fatal Storm** (5 hits rapides)
6. Appliquer **DoT** si disponible

**Phase 3: Reset**
7. Si l'ennemi survit, **Stealth again**
8. Repeat Phase 1-2

**Tips** :
- ✅ **Toujours surprise attack**
- ✅ **Ne jamais fight face-to-face**
- ✅ **Stun lock** si possible
- ❌ **Ne pas rester visible** sans stealth

#### INT Spear Nuker Strategy

**Phase 1: Opening**
1. Appliquer tous les **buffs** (Fire Force, Lightning Speed, Cold Armor)
2. **Nuke** de loin avec Spear Nuke

**Phase 2: Kiting**
3. Si l'ennemi s'approche, **reculer (kiter)**
4. **Ghost Spear AOE** pour slow
5. Continue nuking à distance

**Phase 3: Finish**
6. Quand l'ennemi est < 30% HP, **Flying Dragon** finisher
7. **Anti-Devil Arrow** (si bow hybrid) pour kill

**Tips** :
- ✅ **Jamais let enemy touch you**
- ✅ **Kiter, kiter, kiter**
- ✅ **Mana management** critique
- ❌ **Ne pas panic si touché**

#### Warlock/Cleric Strategy

**Phase 1: Debuff Application**
1. **Red Debuff** (-50% PHY DEF)
2. **Blue Debuff** (-50% MAG DEF)
3. **Green Debuff** (-50% ATK)

**Phase 2: DoT Setup**
4. Appliquer **3 stacks de DoT**
5. **Kiter** pendant que les DoT tick

**Phase 3: Control**
6. **Sleep** si l'ennemi essaye de healer
7. **Root** pour empêcher kite
8. **Refresh DoT** avant qu'ils expirent

**Tips** :
- ✅ **Patience is key** - les DoT prennent du temps
- ✅ **Ne pas panique** si vous prenez des dégâts
- ✅ **Heal pendant les DoT**
- ❌ **Ne pas waste mana** sur des nukes inutiles

## 🔄 Counters et Matchups

### Matchup Guides

#### Warrior/Cleric vs Rogue/Cleric
**Warrior/Cleric Advantage** :
- Plus tanky
- Peut survivre au burst rogue
- **Stratégie** :
  - Guard Buff up
  - Attendre le KD
  - Heal à travers le burst
  - Une fois OOM rogue, 2H burst

**Rogue/Cleric Advantage** :
- Plus de dégâts
- Peut reset avec stealth
- **Stratégie** :
  - Stealth → KD → Full burst
  - Reset si le warrior est > 50% HP
  - Continue jusqu'à OUM warrior

#### Warrior/Cleric vs INT Nuker
**Warrior/Cleric Advantage** :
- HP énormes pour survivre aux nukes
- **Stratégie** :
  - Guard Buff + Bless Spell
  - Chase et 2H attack
  - Laisser le nuker OOM

**INT Nuker Advantage** :
- Dégâts énormes
- **Stratégie** :
  - Kiter à distance
  - Nuke, kite, nuke
  - Ne jamais let warrior get close

#### Rogue/Cleric vs INT Nuker
**Rogue/Cleric Advantage** :
- Burst énorme
- INT nuker est fragile
- **Stratégie** :
  - Stealth → Stun → Full burst
  - Kill en une seule combo

**INT Nuker Advantage** :
- AOE si rogue se reveal
- **Stratégie** :
  - Ne jamais let rogue get close
  - AOE pour reveal stealth
  - Nuke à distance

## ❓ FAQ

### Q: Quel est le meilleur build PvP 110 cap ?
**R:** **Warrior/Cleric (Pure STR)** est largement considéré comme le meilleur build 1v1 grâce à sa combinaison de dégâts et de survie.

### Q: Le full STR Bow est-il bon en PvP ?
**R:** **Oui**, mais il est très skill-dependent. C'est excellent pour kiter, mais si l'ennemi vous touche, vous êtes en danger.

### Q: Pure INT ou STR pour PvP ?
**R:** **STR pour la plupart des cas**. Pure INT est très fort mais très fragile et difficile à jouer. Pure STR est plus pardonnable.

### Q: Quel armor set pour PvP ?
**R:** Dépend du build :
- **Warrior/Cleric** : Armor (max HP/DEF)
- **Rogue/Cleric** : Garment (speed)
- **INT Nuker** : Garment (MAG DEF++)

### Q: Le +11 est-il nécessaire pour PvP ?
**R:** Sur la plupart des serveurs compétitifs, **oui**. Le +9 est acceptable pour débuter, mais le +11+ est standard pour PvP sérieux.

### Q: Quel est le build le plus difficile à maîtriser ?
**R:** **Rogue/Cleric** a le skill ceiling le plus élevé. Très fort si bien joué, mais très mauvais si mal joué.

### Q: Le Warlock/Cleric est-il viable en PvP ?
**R:** **Oui**, mais c'est un playstyle très lent. Vous ne "burst" pas, vous laissez les DoT tuer lentement.
