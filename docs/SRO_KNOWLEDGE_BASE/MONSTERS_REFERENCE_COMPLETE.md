## 💪 Champion/Giant/Elite

### Types Spéciaux

#### Champion Monsters
- **Apparence:** Aura rouge, taille augmentée
- **Stats:** ×2 HP, ×1.5 ATK
- **Drops:** ×2 gold, ×3 drop rate
- **Spawn:** Aléatoire dans zones normales

#### Giant Monsters
- **Apparence:** Taille massive, aura bleue
- **Stats:** ×5 HP, ×2 ATK
- **Drops:** ×5 gold, ×5 drop rate
- **Loot:** Items rares possibles

#### Elite Monsters
- **Apparence:** Aura dorée, effet spécial
- **Stats:** ×10 HP, ×3 ATK
- **Drops:** ×10 gold, rare drops
- **Loot:** Seal equipment possible

### Farming Strategies

#### Champion Hunting
- **Zones:** Ong Habitat, Shedim Territory
- **Strategy:** Scan pour auras rouges
- **Reward:** Bonus loot, gold

#### Giant Hunting
- **Zones:** High-level zones (70+)
- **Strategy:** Full party recommandé
- **Reward:** Rare items, beaucoup de gold

👉 **Détails:** [MONSTERS_DATABASE.md](MONSTERS_DATABASE.md#championgiantelite-stats)

## 💻 Implémentation Technique (SRObro)

### Database Schema

```typescript
// Prisma schema pour les monstres
model Monster {
  id            String   @id
  name          String
  level         Int
  type          MonsterType // NORMAL, AGGRESSIVE, CHAMPION, GIANT
  zoneId        String
  zone          Zone     @relation(fields: [zoneId], references: [id])
  stats         MonsterStats
  drops         MonsterDrop[]
  spawns        MonsterSpawn[]
}

model MonsterStats {
  id            String   @id
  monsterId     String   @unique
  monster       Monster  @relation(fields: [monsterId], references: [id])
  hp            Int
  phyAtk        Int
  magAtk        Int
  phyDef        Int
  magDef        Int
  critRate      Float
  attackRating  Int
  parryRatio    Int
}

model MonsterSpawn {
  id            String   @id
  monsterId     String
  monster       Monster  @relation(fields: [monsterId], references: [id])
  position      Position // { x, y, z }
  respawnTime   Int      // seconds
  spawnRadius   Int      // meters
  maxCount      Int      // max instances
}

model MonsterDrop {
  id            String   @id
  monsterId     String
  monster       Monster  @relation(fields: [monsterId], references: [id])
  itemId        String
  item          Item     @relation(fields: [itemId], references: [id])
  dropRate      Float    // 0.0-1.0
  minQuantity   Int
  maxQuantity   Int
}
```
