- **Drops:** 1D gear, gold, mats

#### Bandit Stronghold (Levels 10-20)
- **Monstres:** Bandit Archer, Bandit Fighter
- **Coords:** X: 1100-1300, Y: 1200-1400
- **Spawn:** Medium
- **Drops:** 2D gear, gold

## 💪 Champion/Giant/Elite

### Types Spéciaux (valeurs vérifiées/rapportées 2026)

#### Champion Monsters
- **Apparence:** Taille augmentée, nom jaune
- **Stats:** **~×2 HP** (vérifié), ATK supérieure
- **Drops:** Supérieurs au normal
- **Spawn:** Aléatoire dans zones normales

#### Party Monsters
- **Stats:** **~×10 HP** (vérifié communauté) — packs conçus pour les parties

#### Giant Monsters
- **Apparence:** Taille massive, nom rouge
- **Stats:** ×5-10 HP (estimations), ×2-3 ATK
- **Drops:** ×5 gold (rapporté), items rares possibles
- **Party Giant:** ~×20 HP (rapporté) — le plus dur des monstres réguliers

#### ⚠️ « Elite » Monsters
- **NON CONFIRMÉ dans les données client** — probablement variantes Strong (events), party giants, ou serveurs privés. À traiter comme non vérifié.

#### Event Monsters
- **Codes `MOB_EV_*`** (Young Bear...) + variantes **Strong/Evil** (Strong Ong ~30x HP du normal, Strong Tiger Girl `_L2`, Evil `_L3`) + raiders de trade (bandits qui attaquent les caravanes)

### Farming Strategies

#### Champion Hunting
- **Zones:** Ong Habitat, Shedim Territory
- **Strategy:** Scan pour auras rouges
- **Reward:** Bonus loot, gold

#### Giant Hunting
- **Zones:** High-level zones (70+)
- **Strategy:** Full party recommandé
- **Reward:** Rare items, beaucoup de gold

👉 **Détails:** [MONSTERS_DATABASE.md](MONSTERS_DATABASE.md#championgiantelite-stats)

## 💻 Implémentation Technique (SRObro)

### Database Schema

```typescript
// Prisma schema pour les monstres
model Monster {
  id            String   @id
  name          String
  level         Int
  type          MonsterType // NORMAL, AGGRESSIVE, CHAMPION, GIANT
  zoneId        String
  zone          Zone     @relation(fields: [zoneId], references: [id])
  stats         MonsterStats
  drops         MonsterDrop[]
  spawns        MonsterSpawn[]
}

model MonsterStats {
  id            String   @id
  monsterId     String   @unique
  monster       Monster  @relation(fields: [monsterId], references: [id])
  hp            Int
  phyAtk        Int
  magAtk        Int
  phyDef        Int
  magDef        Int
  critRate      Float
  attackRating  Int
  parryRatio    Int
}

model MonsterSpawn {
  id            String   @id
  monsterId     String
  monster       Monster  @relation(fields: [monsterId], references: [id])
  position      Position // { x, y, z }
  respawnTime   Int      // seconds
  spawnRadius   Int      // meters
  maxCount      Int      // max instances
}

model MonsterDrop {
  id            String   @id
  monsterId     String
  monster       Monster  @relation(fields: [monsterId], references: [id])
  itemId        String
  item          Item     @relation(fields: [itemId], references: [id])
  dropRate      Float    // 0.0-1.0
  minQuantity   Int
  maxQuantity   Int
}
```
