## 🎯 Vue d'Ensemble

**SP Farming** est la pratique de farmer des **Skill Points** en maintenant volontairement un écart (GAP) entre votre level et vos mastery levels.

### Points Clés
- ✅ **Essential pour max les masteries**
- ✅ **GAP system:** More gap = more SP per mob
- ✅ **Requires patience:** Slow leveling
- ✅ **Long-term investment:** Worth it!

---

## 🔄 Qu'est-ce que le SP Farming?

### Concept

Le **SP Farming** (Skill Point Farming) consiste à:
1. Monter votre character level
2. Mais **ne pas** monter vos mastery levels au même rythme
3. Cela crée un **GAP**
4. Plus le GAP est élevé, plus vous gagnez de SP

### Pourquoi SP Farming?

**Sans SP Farming:**
- Vous arrivez à level 80
- Vous avez ~1M SP
- Vous pouvez max 1-2 masteries
- **Missing many skills!**

**Avec SP Farming:**
- Vous arrivez à level 80
- Vous avez ~3-5M SP
- Vous pouvez max toutes vos masteries
- **All skills unlocked!**

## 📊 Système de GAP

### Qu'est-ce que GAP?

**GAP** = L'écart entre votre **Character Level** et votre **Highest Mastery Level**

**Formule:**
```
GAP = Character Level - Highest Mastery Level
```

**Example:**
- Character Level: 50
- Bicheon Mastery: 30
- Lightning Mastery: 10
- Force Mastery: 25
- **Highest Mastery: 30**
- **GAP: 20** (50 - 30 = 20)

**Important:** Seul le **highest mastery** compte pour le GAP, pas le total!

### Mastery Cap System

**300 Mastery Points Cap:**
- Maximum total de tous les masteries combinés: **300 levels**
- Chaque mastery peut aller jusqu'à level 80 (max level actuel)
- Example de distribution possible:
  - 3 masteries à 80 = 240
  - 1 mastery à 60 = 60
  - **Total: 300**

**Skill Point Cost per Mastery Level:**
```
Mastery Level 1-10:  Cumulative cost (1+2+3+...+10) = 55 SP
Mastery Level 11-20: Cumulative cost ~200+ SP
Mastery Level 70-80: Cumulative cost ~2,500+ SP per mastery
```

**400 SXP = 1 SP** (constant across all levels)

### GAP et SP/XP Ratios (VERIFIED DATA)

**Research-Based XP/SP Ratios:**

Le ratio XP/SP change de manière **non-linéaire** avec le GAP. Voici les ratios relatifs confirmés par la communauté:

| GAP | Relative SP/XP Ratio | Description |
|-----|---------------------|-------------|
| **0** | 19.36 | Baseline: 19x plus d'XP que de SP |
| **1** | 15.87 | -18% SP gain vs GAP 0 |
| **2** | 13.01 | -33% SP gain vs GAP 0 |
| **3** | 10.41 | ~2x moins de SP qu'à GAP 9 |
| **4** | 8.33 | -57% SP gain vs GAP 0 |
| **5** | 6.50 | -66% SP gain vs GAP 0 |
| **6** | 4.89 | -75% SP gain vs GAP 0 |
| **7** | 3.46 | -82% SP gain vs GAP 0 |
| **8** | 2.17 | -89% SP gain vs GAP 0 |
| **9** | 1.00 | **MAXIMUM SP**: 19x plus de SP qu'à GAP 0 |

**Règle empirique:** Chaque augmentation de 3 GAP = ~2x plus de SP (ou 1/2 moins d'XP)

**Exemples concrets (niveau 16, mob niveau 16):**

- **GAP 0:** 100 SP / 400 XP (total: 500 XP)
- **GAP 6:** 185 SP / 230 XP (total: 415 XP)
- **GAP 9:** 220 SP / 30 XP (total: 250 XP)

**Note:** Le SP est "plus cher" que l'XP. Vous gagnez moins d'XP total mais beaucoup plus de SP.

## 🎯 Optimal GAP

### Recommandations par Level

**Level 1-20:**
- **GAP 0-2**
- Just level normally
- No need to farm SP yet

**Level 20-40:**
- **GAP 4-5**
- Start farming
- Moderate bonus

**Level 40-60:**
- **GAP 7-9**
- **Critical period!**
- Maximum efficient farming

**Level 60-80:**
- **GAP 9-10**
- **Maximum SP farming**
- This is your LAST chance!

**Level 80+:**
- GAP doesn't matter anymore
- You should have enough SP

### Full SP Goal

**Pour 3 masteries maxed (level 80):**
- **~2-3M SP needed**
- Calcul: 3 masteries x 120 SP per mastery x 30 skill points per mastery

**Pour full build (level 100+):**
- **~4-6M SP needed**

## 👕 SP Gear

### Armor: Garment (Light)

**Why Garment?**
- **-20% MP consumption**
- High MAG DEF (si vous êtes INT)
- +10% movement speed (kiting)

**Essential for SP farming!**

### Weapon

**INT Builds:**
- **Garment weapon** (si disponible sur votre serveur)
- Moins de MP cost
- Alternative: Regular weapon

**STR Builds:**
- Regular weapon fine
- Garment less critical

### Accessories

**MP Regeneration:**
- Rings/Necklaces with +MP
- MP regeneration important

**MP Increase:**
- MP jewelry
- Plus de MP = moins de potions

## 🧮 Calculs de SP (VERIFIED FORMULAS)

### Formula de Base

**Conversion SXP → SP:**
```
400 SXP = 1 SP (constant)
```

**SP Gained per Level:**
```
SP per Level = (Required XP to Level) × (SP/XP Ratio) ÷ 400
```

### Calcul de SP Nécessaire

**Exemple: Build Standard (3 masteries maxed)**
- Target: Level 60 avec 3 masteries complètes
- SP Nécessaire: ~92,000 SP
- Options:
  - **Option 1:** Maintenir GAP 4 du début à la fin
  - **Option 2:** SP farm ~20,000 SP dans les levels 1-20, puis GAP 3 ensuite

**SP Requirements Approximatifs:**
- 2 masteries maxed (level 60): ~60,000 SP
- 3 masteries maxed (level 60): ~92,000 SP
- 4 masteries maxed (level 80): ~200,000 SP
- Full build (level 100+): ~400,000-600,000 SP

### Impact du Level sur le Ratio

**Important:** Le ratio SP/XP se dégrade naturellement avec les levels plus élevés!

**Exemple:**
- GAP 5 à level 10 = Meilleur ratio que GAP 5 à level 20
- GAP 5 à level 20 = Meilleur ratio que GAP 5 à level 30
- **Conséquence:** SP farm tôt dans le jeu = plus efficient!

**Recommandation:** Commencez le SP farming dès level 14-16 pour maximum d'efficacité.

### Party Bonus

**Experience Distribution (Party Setting):**
- +3% EXP/SP pour chaque membre additionnel
- Full party de 4 = +9% EXP/SP bonus
- 8/8 party = bonus additionnel (valeurs non confirmées)

**Important:** Le party bonus s'applique à la fois à l'XP et au SP!

## 🎮 Strategy

### Preparation

**1. Get to Level 40:**
- Level normally to 40
- Don't worry about SP yet

**2. Get Gear:**
- **Garment set** (-20% MP)
- SP weapon (si possible)
- MP accessories

**3. Stock Supplies:**
- **TONS of MP potions** (1000+)
- Moderate HP potions
- Speed scrolls

**4. Choose Spot:**
- Level 40-50: Ong Habitat
- Level 50-60: Bunwangs
- Level 60-70: Mu jun

### During Farming

**Pull Strategy:**
- Pull as many mobs as possible
- AOE them down
- Repeat

**For INT:**
- Nuke from range
- Kite if necessary
- Use Chain skills

**For STR:**
- Pull groups
- AOE skills
- Use potions

**Mana Management:**
- Use MP potions liberally
- Don't let MP hit 0
- **Efficiency is key!**

**Buffs:**
- Lightning speed (for kiting)
- Any MP reduction buffs

### Tips

**1. Be Patient:**
- SP farming is BORING
- But essential
- Listen to music, watch videos, etc.

**2. Take Breaks:**
- Burnout is real
- Farm in 1-2 hour sessions

**3. Party:**
- 2-person party = More EXP, same SP
- Faster level gains but same SP

**4. Don't Over-Farm:**
- Once you have enough SP, stop
- Move on with leveling

## ❓ FAQ

### Q: SP farming est-il obligatoire?
**R:** Non, mais fortement recommandé. Sans SP farming, vous serez "skill-starved" à haut level.

### Q: Combien de SP pour max 3 masteries?
**R:** Environ 2-3M SP pour level 80 cap. 4-6M SP pour level 100+.

### Q: Le GAP 10 est-il le maximum?
**R:** GAP 9-10 donne le maximum bonus. GAP supérieur ne donne pas plus de SP.

### Q: Puis-ai-ai SP farm à level 100?
**R:** Vous pouvez, mais c'est moins efficace car les mobs donnent moins de SP ratio.

### Q: Les mobs champion/giant donnent-ils plus de SP?
**R:** Oui, mais le ratio SP/EXP est le même. C'est plus efficient de farmer des mobs normaux plus vite.

### Q: Le SP farming fonctionne-t-il pour les Européens?
**R:** Non, les Européens n'ont pas besoin de SP farming car ils n'ont pas le système de mastery points.
