## 🎯 Vue d'Ensemble

Le système de **Degrees** dans Silkroad Online est la méthode principale de classification des équipements selon leur **level requirement**.

### Points Clés
- ✅ **13 Degrees:** 1D à 13D
- ✅ **Level ranges:** Chaque degree couvre ~10 levels
- ✅ **3 Categories:** Weapons, Armor, Accessories
- ✅ **Visuals:** Chaque degree a un look unique
- ✅ **Stats:** Plus le degree est haut, plus les stats sont élevées
- ✅ **Enhancement:** Peut être amélioré avec l'alchimie
- ✅ **Seal versions:** SOS, SOM, SOSun disponibles pour chaque degree

### Pourquoi le Système de Degrees?

**Progression Naturelle:**
- Force les joueurs à changer d'équipement régulièrement
- Chaque degree offre une amélioration visible
- Crée une courbe de progression claire

**Market Structure:**
- Chaque degree a son propre marché
- Les joueurs vendent/achètent par degree
- Économie dynamique

---

## 📊 Système de Degrees (1D-13D)

### Rules de Base

**Level Requirement:**
- Chaque degree a un **level minimum** pour être équipé
- Exemple: 5D items nécessitent level 40+

**Progression:**
- Généralement ~10 levels par degree
- Plus le degree est haut, plus l'équipement est puissant

**Max Level:**
- Official cap: 110 (13D)
- Some private servers: 120-140 (14D-15D custom)

## 🎒 Types d'Équipements

### 3 Catégories Principales

#### 1. WEAPONS (Armes)

**Chinese:**
- Sword, Blade
- Spear, Glaive
- Bow

**European:**
- 1H Sword, 2H Sword/Axe
- Dagger
- Crossbow
- Staff (Wizard, Warlock, Cleric, Bard)

**Stats:**
- **Physical Attack:** Pour les weapons physiques
- **Magical Attack:** Pour les staffs
- **Critical:** Certains weapons ont +crit
- **Attack Rating:** Chance de hit
- **Block Rate:** Pour les shields

#### 2. ARMOR (Armures)

**3 Types:**
- **Armor (Heavy):** High PHY DEF, low MAG DEF
- **Protector (Medium):** Balanced DEF
- **Garment (Light):** High MAG DEF, low PHY DEF

**Stats:**
- **Physical Defense:** Réduit les dégâts PHY
- **Magical Defense:** Réduit les dégâts MAG
- **Parry Ratio:** Esquive passive
- **Block Rate:** Pour shields

**Slots:**
- Head, Chest, Shoulders, Legs, Boots
- Shield (optional)

#### 3. ACCESSORIES (Accessoires)

**3 Types:**
- **Ring (2x):** Stats boost
- **Necklace:** Stats boost
- **Earring (2x):** Stats boost

**Stats:**
- **STR/INT:** Primary stats
- **HP/MP:** Health/Mana
- **PAR/ERR:** Parry ratio, Evasion rate
- **Critical:** Crit chance

## 🛡️ Armor

### 3 Types d'Armor

#### ARMOR (Heavy)

**Stats:**
- **Highest PHY DEF**
- **Low MAG DEF**
- **Speed penalty:** -10% movement speed
- **High durability**

**Pour qui:**
- STR Warriors
- Melee builds
- Tanks

**Example DEF (9D):**
- PHY DEF: 400-600
- MAG DEF: 100-200

#### PROTECTOR (Medium)

**Stats:**
- **Balanced PHY/MAG DEF**
- **No speed penalty**
- **Medium durability**

**Pour qui:**
- Hybrid builds
- Balanced playstyle
- All-rounders

**Example DEF (9D):**
- PHY DEF: 250-400
- MAG DEF: 250-400

#### GARMENT (Light)

**Stats:**
- **Low PHY DEF**
- **Highest MAG DEF**
- **Speed bonus:** +10% movement speed
- **Low MP consumption** (-20% MP usage)

**Pour qui:**
- INT Nukers
- SP farming (MP efficiency)
- Kiting builds

**Example DEF (9D):**
- PHY DEF: 100-200
- MAG DEF: 500-700

### Armor Slots

| Slot | Description |
|------|-------------|
| **Head** | Helmet, Hat, Hood |
| **Chest** | Armor, Robe, Coat |
| **Shoulders** | Shoulder pads, Cape |
| **Legs** | Pants, Skirt |
| **Boots** | Shoes, Boots |
| **Shield** | PHY or MAG shield (optional) |

### Set Bonuses

Certains sets donnent des **bonus quand tout le set est équipé**:

**Example 9D Set Bonus:**
- +5% PHY DEF
- +5% MAG DEF
- +100 HP
- +50 MP

**Note:** Les set bonuses dépendent du degree et du type (normal vs SOX)

## 📈 Degree Progression

### Typical Progression Path

**Early Game (Level 1-20):**
1. Start with 1D gear (tutorial)
2. Upgrade to 2D at level 10
3. Upgrade to 3D at level 20

**Mid Game (Level 20-60):**
4. Get 4D at level 30
5. Get 5D at level 40
6. Get 6D at level 50
7. Get 7D at level 60

**Late Game (Level 60-110):**
8. Get 8D at level 70

## ❓ FAQ

### Q: Puis-je porter un équipement d'un degree supérieur à mon level?
**R:** Non, vous ne pouvez pas équiper un item si votre level est inférieur au level requirement.

### Q: Est-ce que tous les degrees sont disponibles sur tous les serveurs?
**R:** Non. Les serveurs avec un level cap de 90 n'auront pas de 11D-13D, par exemple. Vérifiez le level cap de votre serveur.

### Q: Quel degree est le plus "fun" à jouer?
**R:** La plupart des joueurs trouvent que 7D-9D est le sweet spot. Vous avez accès à la plupart des skills et l'équipement est abordable.

### Q: Les looks changent-ils avec les degrees?
**R:** Oui! Chaque degree a un look unique. 9D et 10D ont des looks particulièrement appréciés par la communauté.

### Q: Quand devrais-je changer de degree?
**R:** Dès que vous atteignez le level requirement du degree suivant. Cependant, si vous avez du SOX du degree actuel, il peut être préférable de le garder un peu plus longtemps.

### Q: Les items de degree inférieur peuvent-ils être meilleurs que les items normaux du degree supérieur?
**R:** Oui! Un item SOS (Seal of Star) de degree inférieur peut avoir des stats équivalentes ou même supérieures à un item normal du degree supérieur. Par exemple, un SOS 7D peut être aussi bon qu'un normal 8D.

### Q: Combien coûte un full set de 9D?
**R:** Cela dépend énormément du serveur, du type (normal vs SOX), et de l'état du marché. En général, un full set 9D normal peut coûter quelques centaines de millions à quelques milliards de gold.
